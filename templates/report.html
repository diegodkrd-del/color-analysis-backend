CIELAB (L*a*b*) Optical Science & Derivation

The CIELAB 3D Model: Defined by the International Commission on Illumination (CIE) in 1976 to map color based on human visual perception.

  • L* (Lightness): 0 (pure black) to 100 (ideal white). Matches perceived brightness.
  • a* axis (Green/Red): Negative values = green; positive values = red/magenta.
  • b* axis (Blue/Yellow): Negative values = blue; positive values = yellow.
  • Center Point (a* = 0, b* = 0): Represents completely neutral grey, black, or white.

Why CIELAB Matters in Optical Science:

  • Device Independence: Absolute color independent of screens, printers, or camera sensor profiles.
  • Perceptual Uniformity: Distance in space matches perceived visual change.
  • ΔE (Delta E): Quantifies visual difference (\(\Delta E^*_{ab}\)). A \(\Delta E \approx 1.0\) represents a Just Noticeable Difference (JND).
L* = 116·f(Y/Yn) - 16  |  a* = 500·[f(X/Xn) - f(Y/Yn)]  |  b* = 200·[f(Y/Yn) - f(Z/Zn)]
